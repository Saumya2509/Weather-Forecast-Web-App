
# 🌦️ Weather Forecast App

A modern and responsive **Weather Forecast Web Application** built using **React + Vite**, which fetches **real-time weather data** using a public Weather API and displays it in a clean, user-friendly UI.

🚀 Fast | 🌍 Real-time | 📱 Responsive

---

## ✨ Features
- 🔍 Search weather by **city name**
- 🌡️ Real-time **temperature, humidity & conditions**
- ⛅ Weather icons based on conditions
- ⚡ Super fast performance with **Vite**
- 📱 Fully responsive design
- ☁️ Deployed on **Vercel**

---

## 🛠️ Tech Stack
- ⚛️ **React.js**
- ⚡ **Vite**
- 🌐 **Weather Forecast API**
- 🎨 CSS / Tailwind (if used)
- 🚀 **Vercel** for deployment
